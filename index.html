Privacy Policy — Video Speed Controller — Speed & Volume Booster

Last updated: 20 September 2026. This policy describes version 1.1.0.

Video Speed Controller, provided by extenup, controls supported HTML5 video and audio in Chrome. Its playback controls and audio processing run locally. The extension does not send playback data, browsing data, preferences or shortcut events to the developer or an external service. It has no account, analytics, advertising or tracking service.

Information handled locally

The extension uses only information needed for its playback controls:

  • Media elements and playback state. It detects HTML5 video and audio elements and reads their playback rate, volume, mute state, time, duration and screen position. It uses these properties to change speed, adjust normal volume, seek, position on-video controls and show player-reported values in the popup.
  • Addresses used for boost compatibility. When on-video audio boost is requested, it examines the media source URL and current page URL/origin locally to decide whether it can route the source through Web Audio. These addresses are not written to extension storage or included in the popup's player reports. The extension does not keep a browsing history or read Chrome's history database.
  • Shortcut and layout events. It matches physical-key events to your shortcut assignments and checks whether the event comes from an editable field. It also handles scroll and resize events to position the on-video controls. It does not record a keystroke or activity log, read text typed into fields, or collect the text of articles or messages.
  • Temporary control messages. The popup and the extension's page scripts exchange numeric player counts, playback rates, volume/mute values, boost values, failure counts and temporary request IDs. Chrome tab and frame IDs route and combine these local reports. These identifiers and reports are not saved to extension storage or transmitted outside the browser.
  • Compatible audio. When you use the on-video boost control, compatible media audio is processed through the browser's Web Audio API to adjust gain. This feature does not use a microphone, record audio or video, or upload media. Boost may be unavailable for some sources or browser conditions.

The toolbar popup changes speed and normal volume on the current tab. The separate “Apply speed & volume to all tabs” button applies both selected values to loaded, accessible players across open tabs. Popup volume is limited to the normal 0–100% range and does not create an audio-processing graph; above-normal boost is a separate on-video action.

Information saved on your device

The extension uses chrome.storage.local to save your default speed, speed step, rewind/advance interval, boost ceiling, overlay visibility, remember-speed choice and shortcut assignments. When remembering speed is enabled, it also saves the last used speed. Version 1.1.0 stores that remembered value separately from the other preferences and can read the earlier stored format.

These settings are stored in your local Chrome profile, not in the extension developer's servers or Chrome's extension sync storage. The extension does not save page URLs, media addresses, player reports, recordings or key-event histories.

Default and remembered speeds apply to new pages. Changing them does not change players already open. Editing Default speed also updates the next remembered speed. Live settings for an open document remain in memory while that document is open.

Retention and your controls

Saved preferences remain until you change them, reset them or remove the extension. “Reset preferences” restores the extension's default settings and resets its remembered speed. It does not reset current playback speeds or erase your website's own stored settings. Other preferences, including overlay visibility and the boost ceiling, update immediately. Uninstalling the extension removes its local extension storage from that Chrome profile.

Temporary popup reports are discarded when their request or popup ends. Page control state lasts for the current document and ends when that document is closed or navigated away from. You can disable the extension or change its website access through Chrome's extension controls.

Permissions

  • Storage: saves the playback preferences and remembered speed described above on your device.
  • Website access through all-site content scripts: lets controls work on supported HTML5 media across websites and eligible embedded frames. The scripts use the local media properties, address checks, shortcut events and layout information described in this policy. Some protected pages and players cannot be accessed.

Version 1.1.0 does not add a tabs, browsing-history, microphone or recording permission. It uses Chrome's tab messaging with the existing page scripts to perform the current-tab and explicit all-tabs controls.

Network requests and sharing

The extension's code makes no external network requests. It does not sell data, transmit user data to the developer or third parties, or use data for advertising, profiling, analytics, creditworthiness or lending. All extension code is included in its installed package; it does not load remote executable code.

Websites and media providers you visit continue their own normal network activity under their policies. Opening this hosted policy page is also a normal website visit, separate from the extension's local operation. If you choose to email support, the email service handles your message so we can respond.

Limited Use

Video Speed Controller's use of information complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only to provide the playback controls described here. The extension does not make the user's media, page addresses, playback state or shortcut events available to the developer or other people.
